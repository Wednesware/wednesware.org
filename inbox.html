Aug 2, 2026

PSA to AUR users

Due to recent downtime of the Arch User Repository, Nitrogen's latest release, 26.40, and any future releases, along with the li (Lithium) package altogether will not be available on AUR for the time being.

We have no control or info about when AUR will return, but we'll try to push ASAP when it does. Sorry for the inconvenience!

To those affected, please use pipx instead for the time being. Both packages are up-to-date there.

Aug 2, 2026

Lithium 26.1 rollout, future plans

First post of the month! And we have good news!

After a long wait, Lithium has officially rolled out, available on GitHub and PyPI, with an AUR release coming very soon.

We will now begin development of Sourcegen, Hydrogen, Grapple and Atmosphere, likely in that order.

We're planning on posting automated announcements to Wednesware's Bluesky page (wednesware.org) in the future. Don't worry, we'll use original software you can use or fork it yourself! This will not replace Discord or Inbox.

Jul 31, 2026

Iodine, Perkeo/Lithium update, website URL change and Nitrogen AUR release

As July concludes, we're happy to announce the release of a new publication, Iodine. Iodine serves as a modern terminal library focusing on user input with advanced single and multi-line input and choice widgets, syntax highlighting and even suggestions.

There has been lots of development and improvements made to Lithium as it nears its first public release. New syntax includes custom operators, units, and more.

Nitrogen has been released to the Arch User Repository under the name n2 for easy installation on Arch-based distributions. (yay -S n2)

After the release of Lithium 26.1, we'll most likely begin development of Hydrogen and the projects mentioned in the home page before we start remaking all publications for Perkeo.

We now own a domain! You can now find our website at wednesware.org instead of wednesware.github.io, and you can contact us at team@wednesware.org or support@wednesware.org instead of wednesware@gmail.com.

We may also soon start posting announcements and news to Bluesky, along with Discord and Inbox.

Jul 16, 2026

Website rebuild, Perkeo/Lithium news, Oxygen rebranding and Krypton shelving

The wednesware.github.io website has been rebuilt with a responsive multi-page layout for a more professional look and more satisfying feel.

The Perkeo programming language and its ecosystem, Lithium have received massive progress from the team.

There is no estimated time until Lithium 26.1, but the parser and interpreter are basically finished, and libraries and built-ins are now in development.

Oxygen (the terminal color and animation library) has been renamed with Neon due to it being a more fitting name for this library in our opinion. The name Oxygen will now be used for an upcoming perkeo libraries that will start development in the future.

Krypton (the encryption/decryption library) has been shelved for the time being as we work on other publications. Krypton may not return, or return as a completely different library. We may include Krypton's planned features in a future Magnesium release.
